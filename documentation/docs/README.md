# Docs

## Naming convention

`{YYYY-MM-DD}-{feature-name}.md`

## Frontmatter template

```yaml
---
title: "Document Title"

author: agent | username
status: draft | active | superseded | deprecated
migrated_from: bookstack
bookstack_id: <id>
bookstack_url: <url>
related_issues: []
related_mrs: []
---
```
